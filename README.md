# AI SYSTEM CONTEXT

Project: Tính năng Quản lý User (phân hệ Seller Dashboard)

## TECH STACK

- Frontend: React (Functional Components, Hooks)
- Styling: TailwindCSS
- Backend: Node.js, Express.js
- Database: MongoDB

## STRICT RULES FOR AI WORKFLOWS

1. Chỉ sử dụng các công nghệ được liệt kê trong Tech Stack để phân tích và sinh code.
2. Mọi code Frontend phải được style trực tiếp bằng TailwindCSS, không tạo/gợi ý file CSS rời.
3. Backend luôn tạo RESTful API bằng Express.js.
4. Xử lý dữ liệu phải dùng cú pháp của MongoDB.
5. Code ngắn gọn, tập trung vào tính năng CRUD cơ bản.
